07 / 如何解释实验

看“哪一步改善”，也看“还卡在哪里”。

下面是结论判读方式，尚不是实验结果。

如果 ①

规划工具有帮助

混合规划组比 Qwen 基线更好，说明任务拆解可能是关键瓶颈。

→ 继续看动作是否仍失败
如果 ②

诊断工具有帮助

失败后恢复更多、重复错误更少，说明反馈理解可能有改善空间。

→ 同时报告额外调用成本
如果 ③

两者都帮不上忙

先审查视觉证据和动作控制；不能直接断言“规划与诊断无用”。

→ 必须看失败轨迹
原生成功率 / 进度动作合法率 / 恢复率模型调用 / 时间 / 费用相同任务、布局和预算

08 / 第二阶段：让 Qwen 真正学会

先诊断，再训练，最后撤除专家。

训练后仍用独立 RoboDojo 闭环来验收，而不拿离线得分代替机器人成功。

借鉴 RoboICL、ToolRL、Router-R1 等的方法线索；新增论文尚未逐篇核读。Agentic RL 目前是规划，尚未训练模型。
