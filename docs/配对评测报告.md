# 配对评测报告

本次只扩展离线汇总，不改变六组 harness 的行为、模型、预算或集群作业。使用现有 `embodied_agentic.reporting` 命令即可生成新字段；不需要 GPU 或新增依赖。单元测试中的样例数据不是 RoboDojo 实测结果。

## 1. 比较什么

只按相同 `(task_id, seed, layout_id)` 配对有效 episode，成功和进度分仍由原生 `_result.json` 决定。保留原有五个比较，新增此前文档要求但报告未输出的 `hybrid_plan_vs_hybrid_both`：在已有规划建议的基础上，诊断是否还有增量。没有新增实验组。

只输出 schedule 中双方都已安排的比较。即使暂时没有有效配对，也输出 `status=no_valid_pairs`、`paired_episodes=0`，成功率差等未知指标为 `null`，不再让这个比较悄悄消失。

## 2. 分母与正负作用

| 字段 | 含义 |
| --- | --- |
| `valid_control_episodes` / `valid_treatment_episodes` | 两边分别通过现有有效性检查的 episode 数 |
| `unmatched_control_episodes` / `unmatched_treatment_episodes` | 有效但没有有效对应项的数量，不进入配对指标 |
| `control_pair_coverage` / `treatment_pair_coverage` | 配对数除以该侧有效数；有效数为零时未知 |
| `paired_tasks` / `paired_task_layout_groups` | 配对样本覆盖的任务数及任务—布局组合数；不是独立样本数保证 |
| `control_success_rate` / `treatment_success_rate` | 在同一批配对 episode 上计算的两边成功率 |
| `treatment_wins` / `control_wins` | 对照失败而处理成功的数量 / 对照成功而处理失败的数量 |
| `both_succeeded` / `both_failed` | 两边同时成功 / 同时失败；四类数量之和等于配对数 |
| `baseline_failure_rescue_rate` | `treatment_wins / control_failure_episodes`，分母只含配对中的对照失败 |
| `baseline_success_harm_rate` | `control_wins / control_success_episodes`，分母只含配对中的对照成功 |

救回与损害率没有对应机会时为 `null`，不能解释成 0%。这里的“救回”是两次配对运行的结果对比，**不是单条轨迹内部的失败恢复率**，也不是一次专家调用的因果效果。相同 seed 不代表完整中途状态相同。

## 3. 配对成本

`paired_resources` 分别汇总 `estimated_model_cost_usd`、`elapsed_seconds` 和 `executed_physical_steps`。每项都有 `complete_pairs`、`missing_or_invalid_pairs`、`control_mean`、`treatment_mean` 和 `mean_difference`。

- 每项仅使用双方都有有限、非负数值的完整配对；两边均值使用同一批样本，差值方向统一为处理减对照。
- 缺失、布尔值、负数、非数值或非有限数值不补成零；显式记录的零保留。没有完整配对时均值为 `null`。
- 成本缺失不自动剔除该 episode 的有效成功结果。成本完整子集与成功率样本可能不同，必须看各自分母，不能直接宣称“同样本下更省且更成功”。
- 美元金额沿用配置中的模型 token 单价估算，不包含 GPU 租用、队列等待、安装或资产下载。`elapsed_seconds` 沿用 harness episode 的已记录耗时，不是完整集群作业或 RL 训练耗时。
- 定价时要求 summary 的输入/输出 token 计数都为非负整数、两种单价均为有限非负数；字段缺失不能按零 token 估价。报告无法辨别上游是否把缺失 usage 预先写成零，实际费用仍需完整的服务用量记录核对。

## 4. 结论边界

服务故障、未完成运行和缺失轨迹继续按既有规则排除，并保留在 `runs`、`exclusions` 和原生结果汇总中。配对覆盖率只针对有效记录，不是全部计划 episode 的完成率；必须同时查看缺失和排除情况，避免只看幸存样本。

当前输出是描述统计，**没有新增置信区间、显著性检验或能力级归因**。同一布局上的重复 seed 不能直接当成完全独立证据；正式推断需先冻结采样及聚合层级。能力级结论仍需独立的自建议/闭源单项建议对照、信息一致性检查和真实闭环复核，不由此报告替代。
